A Streamlit dashboard that analyzes every prompt sent to Claude Code directly from local JSONL logs with no API key and no data leaving the machine. It combines a CLI plus an interactive dashboard using Apache ECharts via streamlit-echarts, tracking cost and tokens per prompt and project, session-level aggregation, and auto-categorization of prompts.
