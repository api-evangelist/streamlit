This is a Streamlit Components V2 implementation and enhancements for @Rhythrosa (hope that’s ok) original Streamlit Node Editor component. A Streamlit Custom Component v2 for building ComfyUI- and Unreal Blueprints-style node graphs. Users can add nodes, edit parameters, connect typed ports, add, delete, move and select nodes, select and delete connections, auto connect all ports of same type, auto disconnect all ports, change the background colour, border enable/disable, pan and zoom the canvas, and serialize the graph back to Python.
