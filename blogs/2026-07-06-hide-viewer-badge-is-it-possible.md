Hey there, thanks for your question! The “viewer badge” (often the GitHub icon or Streamlit branding in the top right or bottom of the app) can be hidden using custom CSS. There isn’t a built-in Streamlit config option specifically for hiding the viewer badge, but you can inject CSS to hide it.
