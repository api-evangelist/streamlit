**streamlit-markdown-editor** — a dual-mode (WYSIWYG ⇄ raw) markdown editor. Edit markdown in a rich WYSIWYG surface (Milkdown) or toggle to the raw CommonMark source (CodeMirror 6); the two views stay in sync over one canonical string. Markdown in, markdown out.
