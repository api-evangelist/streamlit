Hi everyone! I built an open-source forensic reconciliation tool designed to audit financial inconsistencies between Stripe balance exports and QuickBooks Online clearing ledgers. Instead of generic API syncs that often obscure data gaps, this application focuses on transaction-level integrity: Forensic Ledger Matching: Correlates transaction IDs, payout batches, gross volumes, and processing fees.
