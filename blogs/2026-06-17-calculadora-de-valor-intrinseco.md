A Streamlit app for calculating the intrinsic value of stocks using nine valuation models (Gordon, DCF, Graham, CAPM, and others) with data from Yahoo Finance. It includes an integrated S&P 500 list of 500 tickers, sensitivity tables, and both an interactive CLI and a Streamlit web UI.
