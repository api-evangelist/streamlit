Introducing streamlit-wakeup Hi everyone! I’ve been using Streamlit Community Cloud for hosting portfolio projects, demos, and small prototypes, and wanted a simple way to automate some of the repetitive tasks around managing those deployments. So I built streamlit-wakeup —a lightweight CLI and Python package for automating common Streamlit Community Cloud workflows.
